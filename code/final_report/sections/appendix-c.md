| Term | Meaning in this report |
|---|---|
| High-flow level (Q95) | The {{num:high_flow_percentile}} percentile of a basin's training-years daily flow; a high-flow day exceeds it |
| Onset | A high-flow target day forecast while the flow on the issue day was still at or below the level (Section 2.3); the set grows with the lead |
| Issue time | Local midnight at the end of day t; a forecast for day t+k reads only what exists then |

| Seed rule | A gain is clear only when every training with the input lies above every training without it, most basins agree and a Wilcoxon test rejects (Section 6.3) |
| Matched control | The same input with one thing changed: one day older, over the table's window or over the UTC day (Section 5.4) |
