**The seed rule.** A set is five trainings averaged ({{num:seeds_per_set}} in the stored sets; Section 5.3). A gain is clear only when every training with the input lies above every training without it, most basins move the same way and a Wilcoxon signed-rank test [@wilcoxon1945] over the basins rejects at five percent; otherwise "mixed" or "no clear difference". A Wilcoxon p-value alone therefore does not make a difference clear when single trainings overlap. Paired onset counts use a sign test and, for E3, an exact McNemar test [@mcnemar1947] (p = {{num:e3_mcnemar_p}}); two-seed comparisons carry no p-value; E2 adds a block bootstrap over thirty-day blocks ({{num:e2_fixed_level_points_ci_l2}} and {{num:e2_fixed_level_points_ci_l3}} at two and three days); no multiple-comparison correction was applied.
